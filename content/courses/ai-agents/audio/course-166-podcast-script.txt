[ALEX]: The plugin repo contains a folder—commonly .claude/skills—where each skill markdown lives; optionally a plugin.json manifest lists skill names, versions, authors, and update frequency, letting Claude or Codex index the folder and treat the repo as a library of skills.  
[SAM]: You mentioned auto‑update; how does the agent know to pull the latest version without the user manually doing a git pull?  
[ALEX]: When a user loads a skill, the agent checks the plugin’s repository for new commits; if the HEAD has moved since the last load, it fetches the latest commit automatically, so the next invocation always runs the most recent markdown.
