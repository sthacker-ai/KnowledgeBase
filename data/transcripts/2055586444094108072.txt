The optional flags we are using are inGPULayers99, which tells the server to offload all model layers to the GPU, since running on the CPU is much, much slower. CTX size, which defines our total context, and parallel, which defines how many concurrent requests we can handle at the same time. We also set cache type K and cache type V, which are used to define the quantization type for KV cache. These greatly reduce the memory needed. In addition to this, we are setting flash attention to ON, which also speeds up inference and reduces memory usage. Batch size sets the maximum total token processing batch size for for better throughput during prompt ingestion. U-batch size sets the micro-batch size controlling how work is split internally for GPU efficiency and memory balance. CONT batching enables continuous batching so new requests can be added while others are still running, improving throughput. No context shift prevents automatic shifting of old tokens when context fills up, which helps preserve exact long context behavior. Defragthold sets the KV cache defragmentation threshold When fragmentation reaches 10%, memory cleanup happens to improve performance. And finally, we are setting reasoning to off.
