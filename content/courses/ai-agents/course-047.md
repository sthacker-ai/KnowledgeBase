## Core Concepts

### The Context Window Isn't A Manager
The context window is not a manager, but rather a box with limits that helps to contain and manage the complexity of a project. It is not a substitute for a manager, but rather a tool that can help to facilitate communication and collaboration among team members. A manager is responsible for making decisions and providing guidance, whereas the context window is a tool that helps to provide context and structure to a project.

### One Agent Is The Wrong Unit
One agent is not the right unit of work, as it can lead to a situation where a single task or agent is responsible for an entire project. This can result in a lack of scalability and flexibility, as well as a high risk of failure. Instead, a team of agents working together can provide a more robust and scalable solution to complex problems.

### Small Contracts Beat Giant Prompts
Small contracts are more effective than giant prompts, as they provide a clear and specific set of instructions that can be easily understood and executed. Giant prompts, on the other hand, can be vague and open-ended, leading to confusion and miscommunication. By breaking down complex tasks into smaller, more manageable contracts, teams can ensure that everyone is on the same page and working towards a common goal.

### Receipts Beat BS Vibes
Receipts are more effective than BS vibes, as they provide a clear and tangible record of what has been done. BS vibes, on the other hand, can be vague and subjective, leading to confusion and miscommunication. By using receipts to track progress and provide feedback, teams can ensure that everyone is on the same page and working towards a common goal.

### Claiming Tasks
To claim a task on the Hermes Agent Kanban Board, you need to use the `hermes kanban claim` command. This command allows you to specify the task ID and a TTL (time to live) value. The TTL value determines how long the task will be claimed for, and can be used to prevent the task from being claimed by another agent.

### Blocking Tasks
To block a task on the Hermes Agent Kanban Board, you need to use the `hermes kanban block` command. This command allows you to specify the task ID and a reason for blocking the task. The reason can be used to provide context and feedback to the agent who is blocked.
