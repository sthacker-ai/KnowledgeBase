What if you can run a 70 billion parameter AI model without any supercomputer? It's now possible with an open source Python library called ARLLM. Instead of loading a massive model at once, it loads it layer by layer from your hard drive, just like reading a book page by page instead of memorizing the whole thing first. There's also a feature called Flash Attention, which keeps memory usage almost flat, even with long inputs. input.
