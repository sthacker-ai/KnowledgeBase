## How It Works / Step-by-Step

1. Install the Remotion Agent Skills by running the command `$ npx skills add remotion-dev/skills` in your terminal.
2. Write a code prompt to generate your video. For example, you could use the following code to generate an animation:
```
const remotion = require('remotion');

const animation = remotion.createAnimation({
  durationInFrames: 100,
  fps: 30,
  width: 1920,
  height: 1080,
});

for (let i = 0; i < animation.durationInFrames; i++) {
  const frame = animation.frames[i];
  frame.background = 'red';
}

animation.render();
```
3. Run the code to generate your video. The video will be saved to your local machine and can be shared or uploaded as desired.
