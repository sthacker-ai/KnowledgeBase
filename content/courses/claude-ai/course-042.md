# Understanding and Utilizing Claude Cowork

## Overview
This course will teach you how to use Claude Cowork, a powerful feature of the Claude AI platform, to automate and optimize your workflow. By the end of this course, you will be able to set up Claude Cowork, create and use skills and plugins, and schedule tasks to increase your productivity.

## Background & Context
Claude Cowork is an agentic desktop tool built into the Claude desktop app. It gives Claude direct read and write access to folders on your computer and the ability to execute multi-step tasks autonomously. It differs from Cloud Chat and Cloud Code, which are more conversation-based and coding-focused, respectively. Cowork is designed for non-technical operators and can complete tasks through a visual interface with folders and files.

## Core Concepts

### Claude Cowork
Claude Cowork is a feature of the Claude AI platform that allows you to delegate tasks to the AI. It can read and write files on your computer, execute multi-step tasks, and spin up parallel sub-agents for complex work.

### Skills and Plugins
Skills are repeatable AI workflows, while plugins are extended capabilities that give Claude Cowork more autonomy to complete tasks for you. These features can be created and customized to suit your specific needs.

### Scheduled Tasks
Scheduled tasks allow you to automate Claude Cowork tasks to run at specific times. This can help you manage and organize your work more efficiently.

## How It Works / Step-by-Step

1. Set up Claude Cowork:
   - Sign up for a paid Claude account (Pro or Max).
   - Download the Claude desktop app.
   - Create a new folder for Claude Cowork (e.g., "Claude Workspace") and give Claude full access to it.

2. Create a skill or plugin:
   - Identify a task or process that you want Claude Cowork to automate.
   - Use the Skill Creator tool to turn the process into a reusable skill or plugin.
   - Test the skill or plugin to ensure it works as expected.

3. Schedule a task:
   - Go to the "Scheduled Tasks" tab in the Claude desktop app.
   - Click "Create a new scheduled task" and select the skill or plugin you want to schedule.
   - Set the frequency and time for the task to run.
   - Save the task and monitor its progress.
