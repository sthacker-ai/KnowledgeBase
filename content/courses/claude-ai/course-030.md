Background & Context
-------------------

Claude AI is a powerful AI tool that can be used for a variety of tasks, such as creating presentations, working with Coda-based, and controlling remote sessions for Co-Work and Code. It was created by the number one AIPM voice in Europe, Pavel Hearn, who has over 200,000 LinkedIn followers and over 100,000 newsletter subscribers.

Core Concepts
-------------

### Chat

Chat is a simple interface of Claude AI that allows you to type a question and receive an answer. It can also execute simple scripts, such as drafting an email or summarizing information. However, it is not capable of executing complex workflows or working with real files on your desktop.

### Co-Work

Co-Work is a more advanced interface of Claude AI that allows you to work with real files and execute complex workflows. It can reorganize files on your desktop, create HTML infographics, plan long-running tasks, and spawn sub-agents to execute multiple tasks in parallel. Co-Work runs in a virtual machine and has a different set of plugins that are adjusted to knowledge work, such as organizing a self-improving knowledge database.

### Code

Code is the most advanced interface of Claude AI, and it allows you to execute scripts and system commands on your laptop. It is adjusted to working with code bases and has a variety of plugins that are useful for designing front-end, working with databases, and debugging.

### Skills and MCP Connectors

Skills are pre-built capabilities of Claude AI that allow it to perform specific tasks. MCP Connectors are connectors to external systems and services that allow Claude AI to access and use data from those systems.

### The Skills Marketplace

The Skills Marketplace is a place where you can find and install new Skills and MCP Connectors for Claude AI.

### Strategy Canvas

The Strategy Canvas is a tool that allows you to visualize and plan your product strategy. It can be used to create a self-improving system that builds upon itself, so that every time you do something, the system gets better at doing that task.

How It Works / Step-by-Step
------------------------

1. **Choose the right interface for the task at hand.** If you need to type a simple question and receive an answer, use the Chat interface. If you need to work with real files and execute complex workflows, use the Co-Work interface. If you need to execute scripts and system commands on your laptop, use the Code interface.
2. **Use Skills and MCP Connectors to perform specific tasks.** Skills and MCP Connectors are pre-built capabilities that allow Claude AI to perform specific tasks. To use a Skill or MCP Connector, simply install it from the Skills Marketplace and then call it from the appropriate interface.
3. **Use the Strategy Canvas to plan and visualize your product strategy.** The Strategy Canvas is a tool that allows you to plan and visualize your product strategy. To use the Strategy Canvas, simply open it from the Co-Work interface and start adding elements to your product strategy.
